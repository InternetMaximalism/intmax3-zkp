# Archived specifications

These documents are kept as history only. The official design specification of the current
implementation is [`doc/design_spec.md`](../../design_spec.md) (formerly `detail3.md`); start with its
Overview (chapter 1). Where an archived document and `design_spec.md` disagree, `design_spec.md`
describes the code.

The files are moved here byte-for-byte unchanged (history is not rewritten), so relative links inside
them may be stale.
